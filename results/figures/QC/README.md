# Quality Control and Validation Figures

This directory contains a curated set of quality-control and
validation figures from the GSE210616 TNBC spatial transcriptomics
analysis.

The complete computational outputs remain in the main analysis
results directory. Only representative and summary figures are
included here to keep the GitHub repository manageable.

## RCTD composition

Contains global and all-43-section summaries of inferred cell-type
composition.

The all-43 figures summarize the 43 spatial sections analyzed in
GSE210616.

## RCTD-CNV validation

Contains representative validation figures examining the
relationship between RCTD-derived tumor composition and CNV-based
tumor evidence.

These figures originate from the GSM6433585 validation analysis.

## Tumor threshold / spatial validation

Contains representative spatial validation of the tumor threshold
and combined RCTD/CNV evidence.

These figures originate from the GSM6433585 validation analysis.

## LCP validation

Contains MLCP and SLCP cluster-size and within-cluster
heterogeneity assessments.

## Sample-level validation

Contains three representative GSM6433585 validation figures.

These are explicitly representative sample-level diagnostics and
should not be interpreted as all-43-section summaries.

## Scope

GSE210616 contains 43 spatial sections from 22 patients.

The curated figures are intended to document the major QC and
validation stages of the reproducibility/adaptation workflow without
duplicating the complete set of intermediate diagnostic plots.
