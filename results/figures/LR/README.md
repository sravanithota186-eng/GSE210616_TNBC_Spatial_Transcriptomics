# LR Visualization Figures

This directory contains a curated subset of the ligand-receptor
visualizations generated during the TNBC spatial transcriptomics
analysis of GSE210616.

The complete computational output was generated across 43 spatial
sections. To keep the GitHub repository manageable and readable,
representative spatial maps are provided rather than every
sample-specific map.

## Contents

### spatial_maps/

One representative spatial map for each LR interaction.

### score_distributions/

LR score distributions by spatial niche for the interactions
visualized in the final LR visualization workflow.
