# Spatial Niche Figures

Curated figures from the spatial niche analysis of GSE210616.

## Analysis

Spatial niches were defined from the local organization of LCPs, allowing neighborhoods with distinct MLCP and SLCP compositions to be characterized across the TNBC spatial transcriptomics dataset.

The analysis includes:

- Global niche frequency
- Niche composition
- Sample prevalence
- MLCP–SLCP correspondence
- Sample-by-niche summaries
- Representative spatial niche maps

## Included figures

This curated folder contains **11 figures** covering:

1. Global MLCP niche frequency
2. Global SLCP niche frequency
3. MLCP niche composition
4. SLCP niche composition
5. MLCP niche sample prevalence
6. SLCP niche sample prevalence
7. MLCP × SLCP correspondence
8. Sample × MLCP niche distribution
9. Sample × SLCP niche distribution

11. Representative SLCP niche spatial map

The representative spatial maps are from **GSM6433585**.

## Reproducibility note

The curated figures summarize the spatial niche analysis. The full set of section-level niche maps was generated during the analysis but is not included here in order to keep the GitHub repository focused and manageable.
