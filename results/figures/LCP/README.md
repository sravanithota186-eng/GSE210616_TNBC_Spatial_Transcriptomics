# LCP Figures

Curated figures from the Local Cellular Program (LCP) analysis of GSE210616.

## Analysis

The LCP workflow characterizes local cellular composition patterns across the TNBC spatial transcriptomics sections.

Two LCP levels were evaluated:

- **MLCP** — Major Local Cellular Programs
- **SLCP** — Specific Local Cellular Programs

K-means clustering was used for LCP identification, with:

- MLCP: **k = 32**
- SLCP: **k = 29**

## Included figures

The curated figure set contains:

1. MLCP and SLCP composition summaries
2. MLCP and SLCP spatial maps
3. K-selection evaluation plots
4. Cluster-size summaries
5. Within-cluster heterogeneity validation
6. Representative sample-level spatial maps

The representative spatial maps are from **GSM6433585** and are included as examples of sample-level spatial organization rather than as a complete collection of all 43 section-level maps.

## Reproducibility note

The complete numerical outputs and intermediate analysis files remain in the project results directory. This GitHub folder contains a curated set of figures selected to communicate the major LCP results without uploading all generated intermediate visualizations.
